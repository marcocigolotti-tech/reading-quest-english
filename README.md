# Reading Quest – Meet Eva, Jules & Chiara

Gioco di comprensione della lettura inglese ideato e realizzato dal **Prof. Marco Cigolotti**.

Tre brani originali, 33 domande nel database, 20 domande casuali per partita, feedback, punteggio e lettura vocale inglese.

## Pubblicazione
Carica `index.html`, `README.md` e la cartella `images` nella radice del repository GitHub. Attiva Settings → Pages → Deploy from a branch → main / root.

L’audio usa la sintesi vocale del browser e richiede una voce inglese disponibile sul dispositivo.
